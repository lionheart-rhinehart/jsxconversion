Read the `readme.md` file within this skill, and explore the other available files.

If creating visual artifacts (slides, mocks, throwaway prototypes, etc), copy assets out and create static HTML files for the user to view. If working on production code, you can copy assets and read the rules here to become an expert in designing with this brand.

If the user invokes this skill without any other guidance, ask them what they want to build or design, ask some questions, and act as an expert designer who outputs HTML artifacts _or_ production code, depending on the need.

## Quick map
- `styles.css` — global entry point; link this one file to get all tokens + fonts.
- `tokens/` — colors, typography, spacing, effects, fonts, base reset.
- `assets/` — `logo/` (primary mark), `fonts/` (Saira / Saira Condensed / Space Mono woff2), `reference/`.
- `components/core/` — React primitives (Button, Badge, Tag, Card, ProgramCard, StatTile, Input, Avatar, SectionHeading, Testimonial). Each has a `.prompt.md` with usage.
- `ui_kits/marketing-site/` — homepage recreation. `ui_kits/athlete-portal/` — member app.
- `guidelines/cards/` — foundation specimen cards.

## Brand in one breath
Athletic varsity meets dark arena. Heavy condensed uppercase headlines (Saira Condensed), electric-blue actions, bolt-yellow energy accent, steel-navy panels, near-black surfaces. Voice: a demanding-but-caring coach — short, all-caps, motivational, proof-driven. Tagline: **Train Hard. Rise Higher. Compete Stronger.** No emoji.
