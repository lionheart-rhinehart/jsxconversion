full one. For *how the pipeline works* (not where it lives), read `docs/PROCESS.md` — this map points

## Don't-touch / careful zones

- ⚠️ **`summer/`** — looks like a dead test render folder, **but it's load-bearing.** `.deploy-check.json`
  requires ≥8 MP4s ≥100KB in `summer/**/*.mp4`, and there are **exactly 8** (zero margin). Deleting or
  moving it makes `/full-deploy-light` abort at the gate. *(Latent bug worth a separate fix: the deploy
  gate should point at real campaign output, not a test run.)*
- 🟡 **`Andromeda 1 - noblesville test/`**, **`Testimonial - summer - test/`** — retired test runs (Cody's
  early "what happens if I do this" experiments). Safe to ignore. `Andromeda` is still referenced by
  `planning/…template-library-vision.md` as a known-good example, so it stays in place.
- 🟡 **`jarosh-repurpose.json`, `jarosh-download-manifest.json`** (root) + **`scripts/jarosh-*.mjs`** — one-shot
  `// TEMP:` repurpose tooling (Jarosh is done). The scripts read/write the JSONs by root-relative path,
  so they move together or not at all. Frozen; ignore.
- 🟡 **`repurpose-castille-pelham.json`** (root), **`templates/multi-sport-foundations/_archive-option-b/`** — completed-run artifact / old iteration. Ignore.
- 🚫 **`test/plan2.test.mjs`, `test/plan3.test.mjs`** — regression tests owned by the separate **creative-engine
  hardening** effort. Out of bounds for navigation/cleanup work.

## The data cascade (how a value is resolved)

Values resolve **most-specific wins**:

```
campaign  >  location  >  brand  >  template default
```

Each tier is a JSON file in `data/`: `campaign.<slug>.json`, `location.<slug>.json`,
`brand.<slug>.json`, plus `rules.<slug>.json` for compliance. So a per-location override never bleeds
across locations. Deep detail: `docs/PROCESS.md`.

## The two template banks

- **Static** → `templates/multi-sport-foundations/cluster-*.jsx` (+ `cluster-N.config.json` layer model).
  Rendered via `templates/multi-sport-foundations/_helpers.jsx`.
- **Motion** → `brand/video-templates/templates/*.jsx` (reads `data.*` + `data._overrides[key]`).
  Rendered via `scripts/run-campaign.mjs`. Browseable gallery: `brand/video-templates/serve.mjs` (:5599).

## Naming conventions (full)
