## What's built and working

### Renderer (`.claude/skills/jsx-to-mp4/`)
- Static React → PNG path (added this session)
- Supports image + video media slots
- Font preflight (looks for literal `fontFamily:` patterns in entry file)

### Drag-drop editor (`out/editor/editor.html` + `scripts/editor-server.mjs`)
- Live at http://localhost:5173 when server is running (`node scripts/editor-server.mjs`)
- Move / Crop mode toggle
- Drag text elements, fixedDesign items
- Photo positioning: drag to pan, scroll to zoom, clamped so no black edges
- Photo cropping (Photoshop-style rectangle with 8 handles)
- Foreground media support (transparent-bg cutouts layered in front)
- Font size + text editing inline
- Save + Render button — persists config and triggers renderer
- URL hash sync: `localhost:5173/#cluster-N` direct-loads that cluster

### Compare viewer (`out/compare/compare.html`)
- 22-cluster slideshow (← → arrow keys, prev/next buttons)
- Side-by-side original vs rendered
- "✎ Edit" button jumps to editor for current cluster (press `E`)

### Scaffolder (`scripts/scaffold-cluster.mjs`)
- `node scripts/scaffold-cluster.mjs cluster-N [--force] [--dry-run]`
- Parses Canva SVG, classifies images (background, foreground cutout via mask, decorative)
- Auto-extracts background photo + foreground cutout (real RGBA via puppeteer composite)
- Extracts body `<rect>` elements as fixedDesign (skips bleed rects)
- Generates editor-ready `cluster-N.config.json` + renderable `cluster-N.jsx`

### Shared SVG utilities (`scripts/lib/svg-parser.mjs`)
- `parseSvg`, `extractBodyImages`, `extractBodyRects`, `extractMaskById`, `compositeImageWithMask`, `decodeImageDims`, `resolveClusterSvgPath`
- Used by `inspect-svg-images.mjs`, `extract-cutout.mjs`, `scaffold-cluster.mjs`

## Notable session lessons (also captured in `lessons-learned/`)

- **Pixel-perfect via hand-coded JSX from PNG reference is mathematically unreachable.** Spent 3 iterations on cluster-1 before pivoting.
- **Canva SVG export always outlines text into vector paths**, even with Bulk Create fields marked. Don't try to extract editable text from SVG round-trip.
- **Build the visual editor early.** It cost ~5 hours and saves 20+ across templates.
- **Drag glitches were caused by leaking event listeners on every re-render.** Single global mousemove/mouseup that reads `state.drag = { ... }` is the fix.
- **Live preview must show actual elements, not rendered PNG.** Photo overlays, HTML text overlays — not the baked-together PNG.
- **Pattern-match is the failure mode when recreating designs.** "Corner accent → diagonal stripes" was wrong; actual was "4 stacked horizontal red/black rectangles." List elements literally before coding.
