- `README.md` — brand context, content fundamentals, visual foundations, iconography, file index.
- `colors_and_type.css` — color + type tokens (import first). Core: blue `#017ee6`, green `#59be0b`, ink `#0b1219`, white. Fonts: Oswald (display), Montserrat (body).

- `preview/` — small spec cards for the design system.
