# assets/

Brand assets for Batti-Performance.

## Logo (received & integrated)
The brand mark is a **circular black badge**: an interlocking **BP monogram** in a thin ring, beside the wordmark **BATTI** (red) **−PERFORMANCE** (white).

| File | Use |
|---|---|
| `logo-badge.png` | Full emblem, **chrome** monogram. Primary. 512×512, transparent corners. |
| `logo-badge-white.png` | Full emblem, **flat white** monogram. Alternate. |
| `logo-monogram.png` | Extracted **BP monogram** only — for headers, avatars, favicons, tight spaces. |

Notes:
- The badge's **black circle is part of the mark** — it sits cleanly on white or any light surface, and blends on black (the monogram/wordmark still read).
- For a **monogram on light backgrounds**, request a transparent-background monogram export (the current crop keeps its black fill).
